Sesiones a revisar

        

          

            
          

          
          
          
          
        

        

        

        

        

        
El título lo genera Claude Code automáticamente para cada conversación; no se guardan prompts ni código. Banderas: título con palabras no laborales, horario fuera de L–V 8:00–19:00, sesión sin carpeta de proyecto (Escritorio, Descargas, carpeta de usuario) y costo muy superior a lo habitual.

Carpetas de trabajo conocidas

          
Las sesiones en estas carpetas (y subcarpetas) no levantan banderas de carpeta ni de horario. Se agregan desde la pestaña Sesiones con «marcar carpeta como de trabajo».
